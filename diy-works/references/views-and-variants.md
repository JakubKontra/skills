# Compare layouts and present the approved model

## Resolve the question first

| Request | Useful outcome |
| --- | --- |
| “Does this layout make sense?” | Inspect the existing revision. Point to an actual conflict, shortcoming or opportunity, with a measurement or annotated view where possible. |
| “Try a few options for the oven and corner.” | Compare distinct buildable arrangements from the same baseline. Hold unrelated decisions constant and show the trade-off each option makes. |
| “Definitely option A.” | Use the exact previously presented A as the new baseline. Carry its placement and subsequent accepted edits forward. |
| “Show another angle.” | Add a materially different camera to the approved scene. Choose the viewpoint to answer the unresolved spatial question. |
| “Put the tree in front of the window by the dining table and fridge.” | Identify that particular window, test a realistic seasonal footprint there, and show it together with the table, chairs, and fridge. |

## Alternatives and room audits

For a comparison, retain a short record of the baseline, the user's fixed choices and the variables being tested. Use matching plan crops, viewpoints, furnishings, and lighting across options. Compare tangible quantities as appropriate, such as uninterrupted worktop length, reachable cabinet frontage, number of usable storage modules, or the narrowest passage with doors open. Report measurements in consistent units and name the operating state. Avoid arbitrary scores.

For an open-plan room audit, walk through the activities in the brief. In a kitchen, dining and living space this can include bringing in groceries, loading the dishwasher, sitting at the table, using the fireplace, reaching the record player, and opening the terrace door. Consider simultaneous use by the stated number of people. Distinguish an actual obstruction, a conditional conflict that occurs in one operating state, and an unverified dimension. Prioritise corrections that affect everyday use.

For temporary objects, measure the occupied footprint at its widest point, including branches or chair backs. Start with the requested location and use the real pivots for nearby refrigerator and terrace doors. Test chairs both tucked in and pulled out. Check reachability of the route between its endpoints. A wide gap next to the tree does not prove the route remains continuous. If a passage width is known, one geometric test is to shrink the walkable boundary and expand obstacles by half that width, then check that the endpoints remain in the same connected free-space region. State the boundary and obstacles used. Keep seasonal furniture in its own collection or state so the everyday layout can be recovered. Report a smaller tree, a shifted chair or another placement as a distinct proposal if needed.

## Views that reveal the design

- For placement, use a clean top view with the roof or ceiling hidden only in the view. For heights and joins, use an elevation or cutaway through the actual assembly. Use human-height perspective to show how adjacent spaces feel together. Crop or hide near walls for a presentation view without cutting the design geometry.
- Choose the camera by the question. From a living-room viewpoint show the island, tall units, and dining table together. From the kitchen side show the back of the island and approach to the table. For a tree by a specific window, include enough of the window, table and fridge to confirm which opening it is. For cabinetry over a coffee station, a frontal elevation reveals alignment better than a wide-angle view.
- Check the saved camera frame for objects blocking the view, clipping, exaggerated perspective, or hidden clearances. Use a second detail view only when the general view cannot show the feature. A camera change should not require moving cabinets or fixtures. If an illustrative image is supplied as inspiration, use the actual model for views represented as project geometry.

## Daylight, warm night and coloured scenes

Use the requested lighting states. Build separate controllable groups for daylight, worktop lighting, shelf lights, island extraction lighting, dining pendant, and low-level living-room light where present. Place light sources at the actual fit-out positions. Show the emitter and its effect on nearby work surfaces when the detail matters.

For an even comparison, save named light states and reuse the same cameras, materials, object placement, framing and colour management across variants. Keep any deliberate exposure adjustment identifiable. A warm night scene may use local pools of light at the table and shelves. A coloured scene can retain usable task illumination while accent colours illuminate selected surfaces. A request for Philips Hue above a dining table might specify only the lighting system. Record the actual pendant, light source, mounting height and verified capabilities when selected. Label a visual approximation and identify any missing product dimensions or photometric data.

Render the saved states, inspect each image, and deliver links labelled by location, direction, and lighting condition. For a lighting-only revision, compare the scene's mesh placements to the baseline. For a new viewpoint, confirm the framing actually changed.
